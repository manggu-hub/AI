## 추천 주제 (1번 프리랜싱과 직결)

### ⭐ 1순위: 「하루 만에 쓰는 매출 2배 상세페이지 카피 공식」

- **타겟:** 스마트스토어/쿠팡 셀러, 1인 사업자
- **왜 팔리나:** 셀러는 항상 "안 팔리는 이유"를 검색함. 글쓰기는 외주 비싸고 직접 하긴 막막함
- **차별점:** 이론서가 아니라 **그대로 베껴 쓰는 템플릿 + 실제 예시** 모음
- **가격:** 9,900원 ~ 19,000원 (PDF) / 템플릿 묶음 포함 시 29,000원

### 2순위: 「AI로 마케팅 글 10배 빨리 쓰는 법 (초보용)」
- 타겟: 자영업자, 마케팅 담당 신입, 부업러
- 4번 콘텐츠(유튜브/블로그)와 주제가 같아 시너지

### 3순위: 「부업으로 월 100만원, 크몽 카피라이팅 시작 가이드」
- 타겟: 부업 찾는 직장인 (당신이 직접 걸어본 길을 파는 것)
- 당신의 실제 수익 인증이 강력한 세일즈 포인트가 됨

## 1순위 전자책 상세 기획

### 제목 후보
- `하루 만에 쓰는 매출 2배 상세페이지 카피 공식`
- `안 팔리던 상품이 팔리기 시작하는 상세페이지 글쓰기`

### 목차 (약 60~80페이지 분량)
```
들어가며 — 좋은 상품이 안 팔리는 진짜 이유는 '글'입니다

PART 1. 팔리는 글의 원리
  01. 고객은 상품을 사는 게 아니라 '변화'를 산다
  02. 모든 카피의 뼈대: 문제 → 공감 → 해결 → 증거 → 행동
  03. 첫 문장(헤드라인)이 80%다

PART 2. 그대로 베껴 쓰는 템플릿
  04. 후킹 헤드라인 30개 템플릿
  05. 본문 구조 5단계 채우기 템플릿
  06. 구매를 부르는 CTA 문구 모음
  07. 신뢰를 만드는 FAQ 작성법

PART 3. 실전 적용
  08. 카테고리별 예시 (식품/패션/뷰티/생활용품)
  09. Before → After 리라이팅 사례 10개
  10. AI(챗봇)에게 카피 시키는 프롬프트 모음 ← 부록 킬러 콘텐츠

부록. 바로 쓰는 프롬프트 20선 + 체크리스트
```

### 판매 채널
| 채널 | 수수료 | 비고 |
|---|---|---|
| 크몽 (전자책) | 약 20% | 국내 1순위, 검색 유입 좋음 |
| 탈잉 | 20~30% | 클래스 연계 가능 |
| 자사 블로그/스토어 | 0~10% | 4번 콘텐츠로 모은 사람에게 직접 판매 |

### 제작 일정 (주 10시간 기준)
| 주차 | 할 일 |
|---|---|
| 1주 | 목차 확정, PART 1 집필 |
| 2주 | PART 2 템플릿 작성 |
| 3주 | PART 3 사례 + 부록 |
| 4주 | 교정, 표지(Canva 무료), 등록 |

> 본문은 나(Claude)에게 "PART 1 1챕터 써줘"라고 하면 초안을 뽑아드립니다.
> `전자책_원고_샘플.md`에 첫 챕터 샘플을 만들어 뒀습니다.

### 표지 만들기 (비개발자/비디자이너)
- Canva(무료) → "전자책 표지" 템플릿 검색 → 제목만 바꾸기
- 제목은 크고, 부제로 베네핏 한 줄, 하단에 저자명

### 가격 전략
- 출시 1주: 50% 할인(4,900원)으로 초기 리뷰 확보
- 리뷰 10개 후: 정가 9,900~19,000원
- 템플릿 파일(노션/워드) 묶음 = 29,000원 업셀
