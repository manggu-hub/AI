# 크몽 서비스 등록글 3종 (복붙용)

> 사용법: 크몽 가입 → "전문가 등록" → 아래 내용을 카테고리에 맞게 붙여넣기.
> 처음엔 **1개만** 등록하고 리뷰 5개 쌓은 뒤 나머지 추가하세요.
> 가격은 초기(리뷰 0~5개) 기준입니다. 리뷰 쌓이면 1.5~2배로 올리세요.

## 서비스 ① 스마트스토어 상세페이지 / 제품 카피 작성 ⭐가장 추천

**카테고리:** 마케팅 > 카피라이팅 / 콘텐츠 제작

**서비스 제목 (둘 중 택1):**
- `매출 올리는 상세페이지 카피, 제품 설명 글 작성해드립니다`
- `클릭을 부르는 스마트스토어 상세페이지 문구 써드립니다`

**서비스 설명:**
```
안녕하세요. 팔리는 글을 쓰는 마케팅 카피라이터입니다.

상품은 좋은데 설명 글이 밋밋해서 안 팔리고 계신가요?
고객의 구매 버튼을 누르게 만드는 상세페이지 카피를 작성해드립니다.

[이런 분께 추천합니다]
· 스마트스토어/쿠팡/자사몰을 운영하는 셀러
· 상품은 자신 있는데 글쓰기가 어려운 분
· 외주 디자이너에게 넘길 "텍스트 원고"가 필요한 분

[작업 내용]
· 후킹 헤드라인 (시선을 잡는 첫 문장)
· 고객 문제 → 해결 → 베네핏 구조의 본문
· 구매를 유도하는 CTA 문구
· 자주 묻는 질문(FAQ) 문구
· 키워드를 반영한 검색 노출 최적화

[작업 방식]
주문 후 간단한 설문(상품 정보, 타겟 고객, 강조점)을 드립니다.
24~48시간 내 초안 → 수정 반영 → 최종 납품.

[차별점]
단순히 예쁜 글이 아니라, "왜 사야 하는지"를 설득하는
세일즈 카피 구조로 작성합니다.
```

**가격 패키지 (3단계):**

| 패키지 | STANDARD | DELUXE | PREMIUM |
|---|---|---|---|
| 이름 | 상품 1개 기본 | 상품 1개 풀패키지 | 상품 3개 패키지 |
| 가격 | 30,000원 | 60,000원 | 150,000원 |
| 본문 분량 | 800자 내외 | 1,500자 + FAQ | 상품 3개 풀패키지 |
| 헤드라인 | 1개 | 3개(A/B 테스트용) | 각 3개 |
| 수정 횟수 | 1회 | 2회 | 3회 |
| 작업일 | 2일 | 3일 | 5일 |

**요청 시 받을 정보 (구매자 설문):**
```
1. 상품명과 한 줄 설명
2. 주요 타겟 고객 (연령/성별/상황)
3. 경쟁 상품 대비 강점 3가지
4. 가격대
5. 참고하고 싶은 톤 (전문적/친근한/고급스러운 등)
```

## 서비스 ② 블로그 / SNS 마케팅 콘텐츠 작성

**카테고리:** 마케팅 > 블로그 마케팅 / 콘텐츠 제작

**서비스 제목:**
- `검색 잘되는 블로그 글, SNS 콘텐츠 작성해드립니다`
- `네이버 블로그 상위노출 글 + 인스타 캡션 패키지`

**서비스 설명:**
```
브랜드와 가게를 알리고 싶은데 글 쓸 시간이 없으신가요?

검색에 잘 걸리고, 읽으면 신뢰가 생기는
블로그 글과 SNS 콘텐츠를 작성해드립니다.

[작업 내용]
· 네이버/티스토리 블로그 포스팅 (키워드 최적화)
· 인스타그램/스레드 캡션 + 해시태그
· 가게/브랜드 소개 글
· 이벤트/프로모션 안내 문구

[작업 방식]
키워드와 핵심 메시지를 주시면
SEO를 고려한 자연스러운 글로 작성합니다.
AI를 활용해 빠르게 초안을 잡되,
사람이 직접 검수해 어색함 없이 마무리합니다.
```

**가격 패키지:**

| 패키지 | STANDARD | DELUXE | PREMIUM |
|---|---|---|---|
| 가격 | 20,000원 | 50,000원 | 120,000원 |
| 내용 | 블로그 글 1개(1,500자) | 블로그 3개 | 블로그 5개 + 인스타 5개 |
| 키워드 최적화 | ○ | ○ | ○ |
| 수정 | 1회 | 2회 | 2회 |
| 작업일 | 2일 | 4일 | 7일 |

## 서비스 ③ 사업계획서 / 제안서 / 정부지원사업 서류 작성

**카테고리:** 문서·글쓰기 > 사업계획서 / 제안서

**서비스 제목:**
- `합격하는 사업계획서, 정부지원사업 서류 작성 도와드립니다`
- `투자/지원사업용 사업계획서 초안 작성 및 첨삭`

**서비스 설명:**
```
사업 아이템은 있는데 글로 정리가 안 되시나요?
창업지원, 정부지원사업, 투자 유치용 서류를
설득력 있는 구조로 작성해드립니다.

[작업 내용]
· 사업계획서 (문제-솔루션-시장-수익모델 구조)
· 정부지원사업 신청서 (예비창업패키지, 청년창업 등)
· IR/투자 제안서 초안
· 기존 서류 첨삭 및 보완

[작업 방식]
아이템 설명을 주시면 심사위원이 보고 싶어 하는
논리 구조로 재구성해 작성합니다.
```

**가격 패키지:**

| 패키지 | STANDARD | DELUXE | PREMIUM |
|---|---|---|---|
| 가격 | 50,000원 | 150,000원 | 350,000원 |
| 내용 | 1개 항목 작성/첨삭 | 사업계획서 1부(5~7p) | 풀 사업계획서 + 발표자료 초안 |
| 수정 | 1회 | 2회 | 3회 |
| 작업일 | 3일 | 5일 | 10일 |

> 사업계획서는 단가가 높지만 책임도 큽니다. 처음엔 ①②로 리뷰를 쌓고
> 자신감이 생긴 뒤 ③을 추가하는 걸 권합니다.

## 크몽 초기 공략 팁 (리뷰 0개 → 첫 10개)

1. **첫 3건은 거의 원가로**: 가격을 위 표보다 30% 낮게 시작 → 리뷰 확보가 1순위
2. **빠른 응답**: 크몽은 응답속도를 노출에 반영. 문의 오면 1시간 내 답장
3. **포트폴리오 필수**: `포트폴리오_샘플.md`의 샘플을 본인 작업물로 등록
4. **무료 첨삭 미끼**: "구매 전 샘플 한 줄 무료" 제안으로 문의 전환율 상승
5. **리뷰 요청**: 납품 후 "만족하셨다면 리뷰 부탁드린다" 정중히 요청
6. 5개 리뷰 모이면 → 가격 정상화, 10개 넘으면 → 1.5배 인상

> AI(나)에게 "이 상품 상세페이지 카피 써줘"라고 하면 실제 작업도 같이 해드립니다.
> 받은 초안을 검수만 해서 납품하면 작업 시간이 1/5로 줄어듭니다.
