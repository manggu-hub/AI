# SaaS 도구 배포 & 수익화 가이드 (비개발자용)

> 당신은 이미 Streamlit 앱(`app.py`)을 돌리고 있습니다.
> 즉, 이 도구도 **똑같은 방법으로** 실행/배포할 수 있습니다. 새로 배울 게 거의 없습니다.

---

## STEP 1. 내 컴퓨터에서 실행해보기 (5분)

```bash
cd monetization/03_SaaS도구
pip install -r requirements.txt        # 이미 깔려있으면 생략
streamlit run app.py
```

- 브라우저가 열리고 도구가 뜹니다.
- `.env` 파일에 `GEMINI_API_KEY=당신의키` 가 있어야 작동합니다 (기존 앱과 같은 키 사용 가능).
- 상품 정보 넣고 "카피 생성하기" → 결과 확인.

---

## STEP 2. 인터넷에 무료로 배포하기 (Streamlit Community Cloud)

**비개발자도 클릭만으로 가능합니다.**

1. 이 코드를 GitHub 저장소에 올립니다 (이미 올라가 있음).
2. https://share.streamlit.io 접속 → GitHub 계정으로 로그인
3. "New app" → 저장소 선택 → 파일 경로 `monetization/03_SaaS도구/app.py` 지정
4. Settings → Secrets 에 아래 입력 (코드에 키를 노출하지 않기 위함):
   ```
   GEMINI_API_KEY = "당신의_API_키"
   ```
5. Deploy 클릭 → 몇 분 뒤 `https://...streamlit.app` 주소가 생깁니다.

이 주소를 사람들에게 공유하면 누구나 웹에서 도구를 쓸 수 있습니다.

> ⚠️ 무료 배포는 누구나 접근 가능 = API 비용이 당신에게 청구됩니다.
> 그래서 아래 '접근 제한 / 과금' 단계가 필요합니다.

---

## STEP 3. 돈 받는 3가지 방법 (난이도 순)

### 방법 A. "내가 쓰는 도구" — 가장 쉬움 (오늘 가능)
- 배포하지 말고 **내 컴퓨터에서만** 사용
- 크몽(1번) 작업할 때 이 도구로 초안을 5배 빠르게 뽑음
- 같은 시간에 더 많은 의뢰 처리 = 시간당 수익 상승
- **추가 개발 0원, 위험 0**

### 방법 B. "전자책 부록" — 쉬움 (2번과 결합)
- 전자책(2번)을 사면 이 도구 접속 링크 + 사용법을 제공
- 도구를 미끼로 전자책 가치를 높여 가격 인상 (9,900원 → 29,000원)
- 접근 제한은 "구매자에게만 비밀번호 공유" 수준이면 충분

간단 비밀번호 잠금 (app.py 맨 위에 추가):
```python
PW = st.text_input("접속 코드", type="password")
if PW != os.getenv("ACCESS_CODE", "myebook2026"):
    st.warning("전자책 구매자에게 제공된 접속 코드를 입력하세요.")
    st.stop()
```

### 방법 C. "월정액 구독 SaaS" — 어려움 (3~6개월 뒤)
진짜 SaaS로 돈 받으려면 ①회원가입 ②결제 ③사용량 제한이 필요합니다.
비개발자가 직접 코딩하지 않고 붙이는 방법:

| 기능 | 비개발자용 도구 |
|---|---|
| 결제 | 페이앱 / 부트페이 / 아임포트 (국내 간편결제 링크) |
| 회원/접근관리 | Supabase (이미 기존 앱에 쓰고 있음!) 로 로그인 |
| 호스팅 | Streamlit Cloud (무료) 또는 Render |

가장 현실적인 시작: **"결제 링크(페이앱) → 결제하면 접속 코드 발급"** 수동 운영.
구독자 30명까지는 수동으로 충분합니다. 자동화는 그 다음에.

## 수익 시뮬레이션 (방법 C 기준)

| 구독자 | 월 구독료 | 월 매출 | API 원가(대략) | 순익 |
|---|---|---|---|---|
| 10명 | 9,900원 | 99,000원 | ~1만 원 | ~9만 원 |
| 50명 | 9,900원 | 495,000원 | ~5만 원 | ~44만 원 |
| 100명 | 14,900원 | 1,490,000원 | ~15만 원 | ~134만 원 |
| 300명 | 14,900원 | 4,470,000원 | ~45만 원 | ~400만 원 |

> 구독료 대비 마진이 크지만, **사람을 모으는 것(4번 콘텐츠)이 진짜 관건**입니다.
