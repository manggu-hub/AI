# 마케팅/사업/재테크 분야 AI 수익화 실행 키트

> 대상: 코딩 못함 · 마케팅/사업/재테크 관심 · 국내(한국어) 시장 · 주 15~30시간
> 목표: 4가지 전략(프리랜싱 / 디지털제품 / SaaS도구 / 콘텐츠)을 **하나의 흐름으로** 굴리기

---

## 핵심 전략: 4개를 따로 보지 말고 "하나의 깔때기"로 연결

4개를 각자 시작하면 분산돼서 다 실패합니다. 아래처럼 **서로 먹여주는 구조**로 묶습니다.

```
        ┌─────────────────────────────────────────────┐
        │  4번 콘텐츠 (블로그/유튜브/인스타)            │  ← 사람을 모으는 입구
        │  "AI로 마케팅 글 10배 빨리 쓰는 법" 등        │
        └───────────────┬─────────────────────────────┘
                        │ 신뢰 쌓인 사람들이 ↓
        ┌───────────────▼─────────────────────────────┐
        │  1번 프리랜싱 (크몽) — 가장 빠른 현금         │  ← 2~4주 내 첫 수입
        │  마케팅 카피/상세페이지/사업계획서 대행       │
        └───────────────┬─────────────────────────────┘
                        │ 일하면서 노하우 축적 ↓
        ┌───────────────▼─────────────────────────────┐
        │  2번 디지털제품 (전자책/템플릿)              │  ← 자는 동안 파는 수입
        │  "스마트스토어 상세페이지 카피 전자책" 등     │
        └───────────────┬─────────────────────────────┘
                        │ 반복 작업을 자동화 ↓
        ┌───────────────▼─────────────────────────────┐
        │  3번 SaaS 도구 (직접 만든 AI 카피 생성기)    │  ← 수익 상한 가장 높음
        │  내가 쓰던 도구를 남에게 월정액으로 판매      │
        └─────────────────────────────────────────────┘
```

**같은 무기(AI 마케팅 글쓰기)를 4번 우려먹는 구조**입니다. 콘텐츠로 모으고, 프리랜싱으로 돈 받고, 그 노하우를 전자책으로 팔고, 도구화해서 구독료를 받습니다.

---

## 우선순위와 타임라인 (현실적)

| 순서 | 전략 | 언제 시작 | 첫 수입 | 이유 |
|---|---|---|---|---|
| 1순위 | **1번 프리랜싱** | 1주차 | 2~4주 | 현금이 가장 빨리 돈다. 자신감·노하우 확보 |
| 2순위 | **4번 콘텐츠** | 1주차 (병행) | 3~6개월 | 모객 채널. 느리지만 1번 단가를 올려줌 |
| 3순위 | **2번 디지털제품** | 2~3개월차 | 1~2개월 | 프리랜싱 노하우가 쌓인 뒤 만들어야 잘 팔림 |
| 4순위 | **3번 SaaS** | 3~4개월차 | 1~6개월 | 1·2번에서 검증된 도구를 제품화 |

**처음부터 4개 동시 시작 금지.** 1번+4번 먼저 → 2번 → 3번 순서.
